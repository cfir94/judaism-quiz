# מסע בארון הספרים

מבחן תרגול אינטראקטיבי בעברית לתלמידי קורס מורי דרך, הכולל 150 שאלות בנושא יהדות.

כל השאלות, התשובות וההסברים מבוססים אך ורק על שלוש מחברות הקורס ב-NotebookLM שסופקו לצורך הפרויקט. לכל שאלה מוצגת הפניה מדויקת למקור בתוך המחברות.

## תחומי הלימוד

- יסודות האמונה, תורה שבכתב ותורה שבעל פה
- ארון הספרים היהודי וההלכה
- הלוח העברי, חגים ומועדים
- תפילה ובית הכנסת
- שבת, כשרות ותשמישי קדושה

## אפשרויות תרגול

- סדר נושאים או ערבוב מלא
- תרגול קצר (25), בינוני (50) או מלא (150)
- משוב מיידי, הסבר ומקור לאחר כל תשובה
- סיכום לפי נושאים ותרגול חוזר של טעויות

האתר מותאם לנייד ולמחשב ונפרס באמצעות GitHub Pages.
